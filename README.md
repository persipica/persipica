# 🇰🇷 한국어

## 👨‍💻 About Me

안녕하세요. 웹 개발자를 목표로 공부하고 있는 **강희수**입니다.

React를 활용한 Frontend 개발과 Java / Spring Boot를 활용한 Backend 개발을 중심으로 공부하고 있습니다.

단순히 화면을 구현하는 것에 그치지 않고,

**Frontend → REST API → Backend → Database**

로 이어지는 웹 서비스 전체의 흐름을 이해하고 직접 구현하는 것을 중요하게 생각합니다.

프로젝트를 통해 회원가입 및 로그인, JWT 인증, Social Login, 상태 관리, 외부 API 연동, Database 연동, REST API 구현 등을 경험했습니다.

개발 중 문제가 발생했을 때는 Browser Console, Network, Backend Log, Stack Trace를 이용하여 문제의 발생 위치를 단계적으로 확인하고 해결하려고 노력합니다.

또한 대학에서 정보보호를 전공하며 배운 지식을 바탕으로, 장기적으로는 **웹 개발과 보안을 함께 이해할 수 있는 개발자**로 성장하는 것을 목표로 하고 있습니다.
